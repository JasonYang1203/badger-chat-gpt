# BadgerChatGPT — AI Chat Web Application

This is a single-page AI chat application built with React and Vite.  
It provides a simple, responsive chat interface where users can send messages and receive AI-generated responses, similar to a lightweight ChatGPT experience.

This project was developed as part of my advanced front-end programming coursework at the University of Wisconsin–Madison.

---

## 🚀 Features

- Clean chat interface with message bubbles for user and assistant
- React state management for the full conversation history
- Loading/state handling while waiting for AI responses
- Automatic message persistence using localStorage
- Modular component-based UI design
- Responsive layout based on Bootstrap

---

## 🧰 Tech Stack

- React + Vite
- JavaScript (ES6+)
- Bootstrap
- HTML/CSS
- LocalStorage API

---

## 🛠️ How to Run Locally

1. Install Node.js and npm  
2. Clone this repository:

   git clone https://github.com/JasonYang1203/badger-chat-gpt.git
   cd badger-chat-gpt

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the URL shown in the terminal (typically http://localhost:5173/)
